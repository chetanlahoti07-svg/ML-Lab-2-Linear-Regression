# Lab 2 - Linear Regression

This project implements Linear Regression models for predicting house prices using the USA Housing dataset.

## Models
- Simple Linear Regression
- Multiple Linear Regression
- Ridge Regression
- Lasso Regression

## Dataset
USA Housing Dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Files
- `Lab_2_Linear_Regression.ipynb` - ML implementation
- `USA_Housing.csv` - Dataset

## Objective
To develop a Linear Regression model for predicting house prices using a suitable dataset.
